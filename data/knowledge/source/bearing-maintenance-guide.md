# Bearing Maintenance Guide

Document ID: BRG-MNT-014  
Revision: 5  
Classification: Synthetic demo data

## Combined vibration and temperature

Elevated vibration combined with elevated bearing temperature can be associated
with inadequate lubrication, contamination, misalignment, excessive load, mounting
damage, or bearing degradation. These possibilities require inspection and should
not be treated as a diagnosis from sensor values alone.

## Reduced-speed operation

Reduced-speed operation may be considered only after an operator reviews current
machine state and confirms that the site's operating procedure permits it. Use a
bounded reduction and monitor vibration, temperature, and motor current throughout
the controlled interval.

Stop the controlled interval if any monitored value increases, a new alarm appears,
or the machine state differs from the approved action request.
